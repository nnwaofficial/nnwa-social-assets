# NNWA social assets

Finished, approved images for NNWA (Nutrition & Wellness Academy) social posts, hosted here so Buffer can fetch them by public URL.

Only published or approved-for-publishing creative belongs here. No drafts, lead data, student data or anything private: this repository is public.

Layout: `YYYY/MM/YYYY-MM-DD-<slug>.png`, named by planned posting date.
